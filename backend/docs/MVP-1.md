# Spendly – MVP 1: Initial Product Release

**Project:** Spendly – Expense Tracker
**Release:** MVP 1
**Status:** Completed
**Date:** November 2026

## 1. MVP Overview

The first Minimum Viable Product (MVP 1) of Spendly has been completed.

This release establishes the core functionality of the application, allowing users to manage their expenses, organise spending through category budgets, import M-Pesa transactions, view financial information in different currencies and securely access their accounts.

The goal of this MVP was to deliver a functional expense-tracking application with the essential features needed to help users monitor and manage their finances.

## 2. Implemented Features

### 2.1 User Authentication

Users can securely access their personal accounts.

Implemented functionality:

- User registration.
- User login.
- Authentication and protected access to user-specific data.

### 2.2 Expense Tracking

Users can record and manage their expenses.

Implemented functionality:

- Create and record expenses.
- Capture expense information.
- Track spending through the application.

### 2.3 M-Pesa SMS Import

Users can import transaction information from M-Pesa SMS messages into the application.

Implemented functionality:

- Import M-Pesa transaction messages.
- Extract relevant transaction information.
- Add imported transactions to expense tracking.

### 2.4 Category Budgets

Users can organise their spending by assigning budgets to different expense categories.

Implemented functionality:

- Create category budgets.
- Set spending limits.
- Monitor spending against allocated category budgets.

### 2.5 Currency Display

Users can select their preferred currency for displaying financial information.

Supported currencies:

- Kenyan Shilling (KES)
- US Dollar (USD)
- Euro (EUR)
- British Pound (GBP)

The current implementation supports currency selection and display. Live exchange-rate conversion using ExchangeRate.dev is planned as a subsequent enhancement.

## 4. MVP 1 Outcome

The first MVP establishes the foundation of Spendly as a personal expense management application.

Users can now:

- Create and access personal accounts.
- Record and track expenses.
- Import M-Pesa transaction information.
- Organise spending through category budgets.
- Select their preferred currency for displaying financial information.

This release provides a working foundation for further development and user feedback.

## 5. Planned Enhancements – Next Release

The following improvements are outside the completed MVP 1 scope and will be considered for subsequent releases:

1. **Live Currency Conversion:** Integrate ExchangeRate.dev to retrieve current exchange rates and automatically recalculate displayed financial values.
2. **Bank SMS Import:** Extend transaction detection and parsing to support bank transaction messages.
3. **Spending Analytics:** Introduce visual reports and spending trends.
4. **Savings and Emergency Funds:** Allow users to establish and monitor savings goals.
5. **Enhanced Transaction Management:** Improve transaction editing, filtering and search.

## 6. Conclusion

MVP 1 of Spendly is completed, delivering the initial core features of the application. The next development phase will focus on improving financial visibility, automating transaction management and helping users make better spending decisions.
